## Project name
Student Portal

## Technologies
Backend: ASP.NET Web API (.NET 8) with **JWT** authentication
Database: MSSQL Server for relational data management
Frontend: React (Typescript) combined with Zustand for state management as well as Bootstrap 5 for UI

## Description
Developed a full-stack web application which simplifies the process of academic administration which refers to students, professors and admin. The application enables **students** to view their enrolled subjects, access grades and professor comments, and to track their academic progress with real-time statistics like average grade, total passed exams and earned ECTS points. Speaking of **professors**, it allows them to view their subject lists, add, modify or delete student grades with optional comments, providing direct feedback. If we're talking about **administrators**, they can create, edit, or delete student and professor acounts, and enroll students in subjects, ensuring smooth system operations.
